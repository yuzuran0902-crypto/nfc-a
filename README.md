# NFC証言ページ

学園祭の謎解き用証言サイトです。6種類のページを、NFC用の短いURLで分けています。先輩は番号3・4・5の3ページがあるため、公開URLは合計8個です。

## 内容を変更する

証言・あいことば・番号・使用画像は `config.js` の `pages` 内で管理しています。AとBでは、通常のあいことばで「証言」、`うらばなし` で「再調査の証言」が表示されます。

見本の画像を交換する場合は、`sample-poster.png` を同じファイル名の画像で置き換えてください。

真相ページでは `truth.png` の表示・保存と、YouTubeの真相動画への移動ができます。

## 注意

このパスワード機能は学園祭の謎解き用の簡易ロックです。静的サイトなので、詳しい人がソースコードを調べると、あいことばや証言を確認できます。個人情報や機密情報の保護には使用しないでください。
