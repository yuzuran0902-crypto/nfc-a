# NFC証言ページ：容疑者A

GitHub Pagesへそのまま公開できる、ビルド不要の静的サイトです。

## 内容を変更する

`config.js` の次の4項目だけを編集します。

```js
window.SITE_CONFIG = {
  nfcNumber: "未設定", // NFC番号
  password: "ミテイ", // カタカナの合言葉
  witnessName: "容疑者A",
  testimony: `証言本文`,
};
```

現在の動作確認用パスワードは **ミテイ** です。入力時の半角カタカナは自動的に全角へ変換され、空白は無視されます。

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内の全ファイルをリポジトリ直下へアップロードします。
3. リポジトリの `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` を `Deploy from a branch` にします。
5. ブランチを `main`、フォルダを `/(root)` にして保存します。

短いURLを優先する場合、リポジトリ名を `あなたのユーザー名.github.io` にすると、公開URLは `https://あなたのユーザー名.github.io/` になります。すでに同名のサイトがある場合は、短いリポジトリ名（例：`n`）を使うと `https://あなたのユーザー名.github.io/n/` になります。

## 注意

このページのパスワード機能は、学園祭の謎解き用の簡易ロックです。静的サイトなので、詳しい人がソースコードを調べるとパスワードや証言を確認できます。個人情報や機密情報の保護には使用しないでください。
